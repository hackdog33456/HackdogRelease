# Phooto Studio 0.36.0 — PhotoStudio 專案遷移與 ICC 內部整合

程式碼與既有 Git 歷史遷入 [PhotoStudio](https://github.com/hackdog33456/PhotoStudio)。本版重新打包目前來源，包含 0.35.0 之後的 ICC 色彩引擎、文件合成、來源影像及照片／AI 工作像素整合。

## 變更

- 納入固定版本 LittleCMS 的 RGB ICC 轉換、描述檔驗證及獨立 Worker 執行。
- 整合 PNG／JPEG／WebP 的來源色彩與方向處理、工作像素驗證、顯影、修片與 AI 回圖轉換。
- 保留既有像素遮色片、相片庫版本歷史與本機 AI 物件選區功能。
- 安裝識別、使用者資料位置、安裝檔 PhootoEditor 名稱及 `phootoeditor-v` 更新標籤保持相容。

## 格式與限制

目前原生格式為 **v19**，catalog 維持 **v6**。舊版不能開啟新格式，升級前請保留原始作品備份。

ICC 仍為內部整合階段：公開 ICC 文件開啟／編輯、相片庫顯影同步、ICC SVG／PSD 匯出及 PSD ICC 匯入仍受限制。這次發布不代表完整 ICC 編輯、Photoshop 相容性或付費 AI 服務已驗收。

Windows x64 安裝檔未簽署。發布附件包含安裝檔、blockmap、`latest.yml` 與 `SHA256SUMS.txt`。測試與建置結果見 [發布紀錄](https://github.com/hackdog33456/PhotoStudio/blob/main/docs/release.md)。
